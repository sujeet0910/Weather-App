# 🌦️ Weather App

A modern and responsive Weather App built using **HTML, CSS, and JavaScript**. It fetches real-time weather information using the OpenWeatherMap API and
displays current weather conditions, hourly forecasts, and a 5-day forecast with a clean and intuitive user interface.

## 🚀 Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature and weather conditions
- 🕒 Hourly weather forecast
- 📅 5-Day weather forecast
- 💧 Humidity information
- 💨 Wind speed
- 🌧️ Rain probability/details
- 📱 Responsive design
- ⌨️ Search using Enter key
- ⚠️ Error handling for invalid city names

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- Fetch API
- OpenWeatherMap API
